# Ford Challenge Mobile

Aplicativo desenvolvido com Expo e React Native para apresentar a Ford Ranger Raptor em uma experiência multiplataforma.

O projeto reúne uma interface interativa com modelo 3D do veículo, tela de especificações e uma página de relatório. A aplicação pode ser executada em mobile e web a partir da mesma base de código.

## Como rodar

### Pré-requisitos

- Node.js 18 ou superior
- npm

### Instalação

```bash
npm install
```

### Ambiente de desenvolvimento

```bash
npm start
```

Esse comando abre o Expo para executar o projeto no dispositivo, emulador ou navegador.

### Atalhos úteis

```bash
npm run android
npm run ios
npm run web
```

### Verificação de lint

```bash
npm run lint
```
